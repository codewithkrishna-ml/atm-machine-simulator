# ATM Machine Simulator 🏪💸

A secure and clean ATM transaction simulation system built in Python using **Object-Oriented Programming (OOP)** principles. This application mimics a real-world Automated Teller Machine, handling secure user validation and financial transactions.

## ✨ Key Features

*   **Secure PIN Verification:** Validates user identity with a secure card PIN check before granting account access.
*   **Cash Withdrawal & Deposit:** Handles real-time deductions and additions to the user's account balance with strict error-checking (e.g., preventing overdrafts).
*   **Balance Inquiry:** Instantly fetches and displays the current updated balance.
*   **Transaction Receipts:** Generates a clean summary statement or transaction breakdown after every successful operation.
*   **PIN Change Option:** Allows users to update their secure banking PIN securely within the active session.

---

## 🛠️ OOP Concepts Implemented

This project showcases clean code and structured application architecture:
*   **Classes & Objects:** Created separate entity blueprints like `ATM`, `Account`, and `Transaction`.
*   **Encapsulation:** Protected account attributes (such as account numbers and direct balances) using private fields, allowing modification only through validated class methods.
*   **State Management:** Effectively tracks state transitions, ensuring actions like withdrawals are only permitted *after* a successful PIN match.
